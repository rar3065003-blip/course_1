# Набор модулей для работы с транзакциями из EXCEL файла.
Course1
Функционал проекта представляет собой интерфейс онлайн справочника
для получения информации о банковских транзакциях из файла Excel в период 3 месяцев
по ключевым словам и в рублях по текущему курсу выбранной валюты.
    В проект заложены следующие функции: 
        Функция принимает excel файл и возвращает объект pd.DataFrame
        Функция записи лога выполнения исполняемой функции -
        сохраняет в лог в файл при задании имени или выводит в консоль
        Функция принимает, DataFrame, возвращает операции за последние 3 месяца
        в строковом виде.
        Функция принимает категорию и возвращает список содержащий товар
        с наибольшим кэшбеком.
        Функция приветствует пользователя согласно времени суток.
        Функция возвращает номер карты и сумму операции с кэшбеком и округлением
        Функция принимает таблицу, возвращает транзакцию с указанием категорий и описанием
        Функция возвращает курс валюты по API
        Функция возвращает стоимость запрошенных тикетов акций в рублях
        Функция возвращает временной период транзакций
